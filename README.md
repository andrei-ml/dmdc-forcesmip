# Dynamic Mode Decomposition with control for Forced Component Estimation Statistical Method Intercomparison

This repository contains implementations of **Dynamic Mode Decomposition with control (DMDc)**–based methods designed to estimate the **forced response from a single climate realization**. These methods were developed and applied within Tiers 2 and 3 of the Forced Component Estimation Statistical Method Intercomparison Project (ForceSMIP).

The repository provides reproducible workflows for estimating forced components and evaluating their performance. A demonstration of basic evaluation results is available in the notebook [demo_evaluation_results.ipynb](demo_evaluation_results.ipynb).

---

## 🧪 DMDc Variants

The following DMDc-based approaches are implemented:

- **DMDc**  
  Estimates the forced component as the sum of the **least-damped DMD mode** and the **linear response to the external forcing**.

- **DMDc-opt**  
  Estimates the forced component using an **optimal perturbation pattern**, derived from the evolution operator that jointly governs the climate variable and the forcing signal.

- **DMDc-p**  
  Estimates the forced response directly under the assumption that the data are generated by a **linear non-autonomous stochastic system**, with the DMDc model representing its deterministic core. Such a forced response definition is equivalent to the **pullback attractor** of the DMDc model.

## 🔧 Getting started

- Clone the repository:

```bash
git clone https://github.com/andrei-ml/dmdc-forcesmip.git
```

- Run the methods in each folder (correct the folder for the ForceSMIP datasets in run-scripts):
```bash
cd DMDc
mkdir Tier2 Tier3
python3 run_dmdc.py

cd ../DMDc-opt
python3 run_dmdc_opt.py

cd ../DMDc-p
mkdir Tier2 Tier3
python3 run_dmdc_p.py
```

- Compute evaluation metrics (correct the folder for the ForceSMIP datasets in the scripts):

```bash
cd ../evaluation_metrics
mkdir Tier2 Tier3
python3 run_evaluation_metrics.py
```
